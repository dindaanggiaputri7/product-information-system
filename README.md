# Product Information System

Mini Project Pemrograman Web.

## Deskripsi

Product Information System merupakan aplikasi sederhana untuk
menampilkan informasi produk dan mengelola informasi stok.

## Teknologi

- PHP
- HTML
- CSS
- XAMPP

## Konsep yang Digunakan

- Variable
- Array
- Multidimensional Array
- Conditional
- Foreach
- Function
- Require Once
- Modular Programming

## Struktur Project

- `config.php` → konfigurasi aplikasi
- `products.php` → data produk
- `functions.php` → fungsi pengolahan data
- `index.php` → tampilan aplikasi
